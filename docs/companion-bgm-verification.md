# 일행 입력·BGM·관리자 경로 검증 기록

- 공개 초대장에서 RSVP와 방명록의 `+ 일행 추가` 제어가 표시되는 것을 확인했다.
- 원형 BGM 버튼의 첫 탭 후 미니 플레이어가 열리고 첫 방문 안내 문구가 제거되는 것을 확인했다.
- 배포 도메인의 `/admin` 경로에서 전용 관리자 로그인 화면이 정상적으로 표시되는 것을 확인했다.
- 이미지·GIF·동영상 업로드 테스트는 관리자 로그인 후 `사진 · GIF · 동영상` 섹션에서 수행한다.
- 참석 응답의 `+ 일행 추가`를 선택하면 `일행 성함 1` 입력칸과 삭제 제어가 즉시 추가되는 것을 확인했다.
