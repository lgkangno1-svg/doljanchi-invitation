# 채원이 첫돌 초대장 최종 QA 체크리스트

## 브랜드·시각 품질

- [x] **주인공 중심성:** 첫 화면에 채원이의 이름, 행사 일시, 장소가 한 번에 읽힌다.
- [x] **고유한 첫돌 인장:** `CW · FIRST YEAR · 2026` 인장과 피치 리본 모티프가 히어로·섹션 라벨·클로징을 연결한다.
- [x] **호텔형 소재감:** 아이보리 스테이셔너리, 에스프레소, 뮤트 피치, 샴페인 골드가 과한 장식 없이 유지된다.
- [x] **기능 섹션 일관성:** RSVP·방명록·계좌 영역에도 금박 선·차분한 타이포그래피·종이 질감을 적용한다.
- [x] **실제 미디어 적응성:** 사진, GIF, 무음 반복 동영상이 히어로와 갤러리에 같은 비주얼 프레임으로 나타난다.

## 모바일 여정

- [x] **핵심 정보:** 첫 화면에서 행사 정보와 공유 행동이 선명하다.
- [x] **길안내:** 지도 미리보기와 네이버지도·카카오맵·티맵·카카오내비 동선이 행사장 카드에 묶여 있다.
- [x] **응답 작성:** 참석 여부, 인원, 선택 연락처, 식사 선택이 한 화면 흐름 안에서 작성된다.
- [x] **마음 전달:** 방명록과 계좌 안내가 분리되어 오입력을 줄인다.
- [x] **공유:** 고정 공유 바와 링크 복사 버튼이 44px 이상의 탭 영역을 제공한다.

## 접근성·안정성·성능

- [x] **키보드 포커스:** 버튼·링크·입력 요소에 명확한 포커스 표시가 있다.
- [x] **동작 줄이기:** `prefers-reduced-motion` 환경에서는 업로드 영상 자동 반복을 멈춘다.
- [x] **미디어 상태:** 이미지와 영상에 로딩·오류·기본 이미지 상태가 있다.
- [x] **개인정보 고지:** RSVP 연락처의 사용 목적과 공개 방명록의 노출 가능성을 안내한다.
- [x] **공유 카드:** 저장된 히어로 이미지가 있으면 서버 렌더링 Open Graph와 카카오 공유 버튼이 우선 사용한다. 영상 히어로는 안정적인 기본 카드 이미지로 대체한다.
- [x] **회귀 점검:** TypeScript 검사, Vitest 16건, 운영 빌드, 모바일·데스크톱 시각 점검, 서버 Open Graph 응답 확인을 완료했다.

## 번들 크기 검토

현재 공개 초대장은 운영 빌드에서 초기 JavaScript 청크가 약 199KB gzip으로 생성되며, 빌드 도구가 500KB 비압축 기준의 분할 권고를 표시합니다. 이 크기는 관리자·지도·공유·미디어 관리 기능을 한 프로젝트에 포함한 결과이며, 첫 화면의 히어로 이미지는 별도 스토리지에서 지연 로드되는 구조입니다. 공개 첫 화면의 체감 성능을 해치지 않는 범위로 판단했지만, 향후 관리자 기능이 더 늘어나면 관리자 경로를 별도 청크로 분리하는 것을 우선 최적화 과제로 둡니다.

## 운영 전 사람의 최종 확인이 필요한 항목

- [ ] 실제 사진·영상에 포함된 가족·하객의 공개 동의를 확인한다.
- [ ] 카카오 개발자 앱의 도메인과 JavaScript 키를 연결한 뒤 카카오톡 실기기 미리보기를 갱신한다.
