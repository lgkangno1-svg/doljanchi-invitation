# 행사장·지도 변경 검증 기록

## 확인 결과

2026-08-22에 모바일 공개 초대장을 확인한 결과, 히어로와 `DATE & VENUE` 카드 모두에서 행사장이 다음 두 줄로 표시되었습니다.

```text
코트야드 메리어트 서울 명동
3층 한양 1+2홀
```

지도 링크 도우미의 자동 테스트는 네이버지도, 카카오맵, 티맵, 카카오내비의 검색·목적지명이 모두 `서울 코트야드 메리어트 명동`만 사용함을 검증합니다. 실제 관리자 세션 보호 경로도 데이터베이스에 저장된 동일한 두 줄 행사장 값을 반환하는 것을 확인했습니다.
