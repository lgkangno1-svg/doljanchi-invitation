# 채원이 사진 갤러리 반영 검증 기록

## 확정한 사진 순서

기존 맨 위 케이크 히어로는 변경하지 않았습니다. 공개 초대장 갤러리는 아래 순서로 사용자 제공 사진 다섯 장을 사용합니다.

| 순서 | 사진 | 공개 배치 |
|---:|---|---|
| 1 | 흰 레이스 의상 인물 사진 | 갤러리의 큰 세로 화보 |
| 2 | 아기 발 디테일 사진 | 오른쪽 작은 디테일 컷 |
| 3 | 벚꽃 아래 웃는 사진 | 넓은 계절 전환 화보 |
| 4 | 가족 손을 잡은 신생아 사진 | 하단 왼쪽 추억 컷 |
| 5 | 벚꽃 아래 니트 보닛 사진 | 하단 오른쪽 봄 화보 |

## 검증 결과

공개 초대장 API는 기존 케이크 히어로 참조와 위 갤러리 사진 다섯 장을 해당 순서대로 반환했습니다. 모바일 전체 화면에서도 케이크 히어로를 유지한 채 다섯 장의 사진이 편집형 갤러리와 계절 전환 영역에 표시되는 것을 확인했습니다.

| 항목 | 결과 |
|---|---|
| 히어로 참조 | 기존 `chaewon-hotel-hero` 유지 |
| 갤러리 참조 | 업로드한 사진 5개, 지정 순서 유지 |
| 모바일 렌더링 | 큰 인물 사진, 발 디테일, 벚꽃 전환, 신생아 손, 벚꽃 보닛 사진 표시 |
| 자동 테스트 | Vitest 18개 파일, 51개 테스트 통과 |
