# 관리자 명단 엑셀 이메일 수신 설정

관리자 화면에서는 현재 RSVP와 방명록을 **엑셀 파일로 바로 다운로드**할 수 있습니다. 다운로드한 파일은 네이버 메일을 포함한 원하는 이메일로 직접 첨부해 보낼 수 있습니다.

관리자 버튼을 눌러 `tnfwod@naver.com`으로 자동 발송하려면, 보내는 이메일 서비스가 필요합니다. 권장 방식은 발신 도메인 인증과 전송 기록을 제공하는 **Resend** 같은 이메일 전송 서비스입니다.

## 자동 발송을 켜기 전에 필요한 정보

| 항목 | 내용 |
|---|---|
| 수신 주소 | `tnfwod@naver.com` |
| 전송 서비스 | Resend 또는 사용 중인 이메일 API 서비스 |
| 비밀값 | 해당 서비스의 API 키 |
| 발신 주소 | 서비스에서 인증된 발신 이메일 주소 |

API 키와 발신 주소를 안전한 환경 변수로 설정하면, 관리자 화면에 **"이메일로 엑셀 받기"** 버튼을 추가할 수 있습니다. API 키와 네이버 메일 비밀번호는 소스 코드나 초대장 데이터베이스에 저장하지 않습니다.
